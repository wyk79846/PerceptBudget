# 普通阶段Fast长测与q20、q10异步基线

2026-11-06。seed17/init1，LIBERO Spatial、Object、Goal、LIBERO-10各10任务，每组40回合，共新增120回合。参数在本轮评测期间固定，所有成功和超时均保留。

## 设置

- 三组均使用现有LeRobot π0.5权重，H=50、去噪5步、BF16、原RTC真实异步、请求时采集最新图像。
- 普通阶段Fast：当前机制一判定为普通缓冲刷新，且未处于夹爪关键区间、上次不是Fast、同窗成本和时延允许时使用Fast；关键刷新使用Full，Fast后至少一次Full。Fast外部64＋腕部256token、无state、保留原位置；Full双图512token、保留state。沿用中频优先/高频回退与低频Continue。
- 固定q20、q10：双视角Full＋state，高频1173/3199/1497.6MHz；分别每20或10控制步启动一次推理，不使用事件刷新、Fast或动态调频。逐请求记录确认平均间隔精确为20和10步。
- Fast成本只用seed7/init0保存输入测量。新增`--fixed-q`复用原固定异步入口，原q30默认值保留；25项相关检查通过。未修改FlashRT、权重、RTC或关键动作阈值。

## 怎么看

普通阶段Fast的三任务开发小测两组均3/3，但扩大后29/40，低于纯Full动态的35/40及之前直接交替的33/40。相对纯Full动态，总能量增加10.74%，时间增加12.47%；两组共同成功28项，能量也增加0.86%。该小表和关键区间判断没有带来整任务收益，当前不替换原Full＋Continue基线。

相对q30，普通阶段Fast全40能量增加0.19%；两组共同成功24项省3.72%，但时间增加11.79%。共同成功项的局部节能不能代替全部任务的质量结果。

固定q20比q30多成功2项，总能量增加14.77%；q10比q30多成功3项，总能量增加66.86%。q10与q20失败任务不同，当前结果呈现频繁刷新和能量的取舍，不将q解释为对每个任务都单调改善的参数。

原纯Full＋Continue相对q20全40省21.17%，共同成功31项省21.56%；相对q10全40省45.78%，共同成功31项省44.83%。报告同时保留q30参照，避免只选更耗能的静态组计算优势。各批次独立运行，全部轨迹差异不能只归因于一个模式开关。

## 内存与续测记录

普通阶段Fast与q10各一次模型加载。q20先完成8项、续完至34项，第三次启动在首个待测长任务前触发RAM保护，无新增有效回合；随后第四次启动完成缺少的6项。已完成回合均未重跑，保护中断不计任务失败。

q20后6项及q10全组使用已有的checkpoint映射词表、按需上传BF16行，释放1004.5MiB常驻GPU词表；Fast组原已采用该存储方式。词表值及Full输出一致性此前已核对，权重、分词、精度和动作算法保持。存储方式与各次中断均写入原始配置和`memory_adjustment.json`，RAM保护线未降低。总模型启动6次，结束确认恢复1173/3199/1497.6MHz。
