## 采样时刻：确认2ms差异

同一动作回放并记录真实传感器采样时刻，物理状态逐步精确匹配。

- 旧采图：第30步图像和 state 都在仿真时刻1.998s采样。
- 精简采图：图像在2.000s补采，state仍来自1.998s，相差2ms，非一整步50ms。
- 同时补采后，原始 state 改变，但本例离散后的 state tokens 不变；固定输入探针输出也不变。

这处时间不对齐应统一，但它不是本例通过 state tokens 直接改变动作的原因。此前只检查“物理没推进、state没替换”，不足以证明图像和 state 同时采样。

这是对抓取失误机制的干预验证，不是完整策略的成功率测试。后续若重新观察、预测，可能产生不同修正。

## 固定输入与计算选择

同一个常驻模型，固定图像、state、噪声、旧尾段、d/s和正式确定性设置，A/B/A/B重放：同一输入重复输出最大差均为0。两组图像产生的小幅动作差，六维后处理动作接下来10步 RMSE 为0.00225。

跨进程重放与历史输出仍有差异，原始32维输出最大差约0.0116–0.0162。两个历史 q30 进程的18项 autotune 选择中，第8、9项选中不同候选。因此跨进程差异不能全部归为图像；autotune 对失败的独立贡献尚未定量分离。

固定输入探针中，仅改成同时刻 state 的输出与原 state 输出完全相同，与离散 tokens 不变相符。

## 旧11/12与新10/12不是同配置复测

LIBERO-10 task3 初始状态和首次预测相同，但旧版第30步启动高频 Full、第40步接管；新版第29步启动中频 Full、第44步接管。RTC 初始延迟、三档频率、精简采图、启动点25ms规则也不同。旧226步成功与新520步超时不能直接解释成同一系统随机失稳。
