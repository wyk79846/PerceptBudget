# 机制一基础参数标定方案

先用旧200回合核查夹爪事件的识别与刷新时机，再选少量参数做闭环比较。首要问题是用户观察到的“尚未到位就提前闭爪”：先还原闭爪前的接近、预测、取图、接续与实际执行，检查新动作是否有机会在闭爪之前改变接近过程。目标是改善抓取、接触阶段的漏响应，保留稳定阶段约20至30步一次刷新的长窗口。当前底座为2026年11月11日固定的最终v4；本方案的候选使用独立实验配置。

## 1 数据和固定条件

开发数据使用原M4的200回合：seed17、27、67、79、109，init1，四个LIBERO集合各10任务。完整保留成功和失败记录，全部任务使用同一套参数。数据索引为[旧200回合原始结果](/home/wyk/workspace/任务产出/perceptbudget/M4/20261107T133827.733437Z-critical-high-mixed-expansion3-seeds/results.json)。

新完成的25个seed不参与这次参数选择。旧200回合用于开发标定，最终效果由冻结参数后的新seed测试确认。

闭环实验固定最终v4的checkpoint、H50、5步去噪、BF16、state、Full/Fast选择、RTC和三档频率。关键动作前16步补刷新关闭，夹爪抬起反馈保留。已完成的87回合补刷新消融是独立实验，结果不混入基础参数的标定成绩。

当前基础值如下：

| 参数 | 当前值 | 检查重点 |
|---|---:|---|
| 夹爪指令分界 | ±0.2 | 指令是否经过这个区间；改变阈值是否改变开闭事件 |
| 连续确认长度 | 2步 | 短暂反转是否漏掉；交接附近是否缺少确认窗口 |
| 减速比例 | 0.5 | 是否漏掉接触前的渐进减速，或把普通波动当成关键点 |
| 转向角度 | 60度 | 是否漏掉重要的小幅调整，或频繁响应普通弯曲 |
| 最小平移指令幅度 | 0.1 | 是否把低幅度接触调整过滤掉；它影响减速与转向判定 |

夹爪阈值作用于预测动作的第七维，用来识别开闭计划；它不是实际夹爪开度阈值，也不能确认物体是否已被夹住。XYZ指令幅度不是物理速度。

## 2 先做旧日志分析

按线上同一套剩余动作提取逻辑回放，使用当时尚未执行的动作、已执行历史和实际交接位置。完整chunk从头检测得到的事件不能直接代替线上事件。

对每次开爪、闭爪记录以下时间线：预测里首次出现、事件开始步、确认窗口、首次被调度器发现、实际采图、结果接续、执行指令切换，以及实际夹爪开度变化。分别统计开爪和闭爪，检查交接前后及预测尾段。

优先检查过早闭爪。对齐模型原预测的闭爪位置、RTC承诺前缀与新旧动作的交接位置，以及实际开始闭爪的位置；结合已有视频或离线物体与夹爪轨迹判断当时是否尚未到位。模型预测已经过早、过早的旧动作已进入承诺前缀、以及执行索引偏差分别列出证据，不先归结为同一个参数问题。物体轨迹仅用于离线分析，不进入线上刷新判断。

若开闭事件已被正确识别，重点统计最近观测距闭爪的跨度、结果距闭爪还剩多少可调整动作，而非只统计闭爪点前是否完成推理。必要时从旧开发记录提出闭爪前接近阶段的刷新窗口候选；候选仍需与原参数成对闭环，不能直接假设统一延后闭爪或固定提前几步就有效。

首先区分三类问题：

- 改变分界或确认长度后，原来没有识别的开闭指令能被识别：属于基础检测候选。
- 指令已被识别，但被阶段去重、供给限制或刷新时限处理掉：属于刷新时机问题，单改夹爪分界不会解决。
- 指令和刷新均正常，仍出现空夹、滑落或位置不对：结合已有动作与state记录分析，不用开闭指令代替抓取成功标签。

离线执行记录可检查预测与后续执行的一致性；它不是“必须在此刷新”的真值。尤其不能把失败回合里的每次闭爪都标为漏刷新。

设计前抽查四类任务各一回合，共1,900条预测动作，仅1条夹爪指令位于±0.2之间，多数开闭指令幅度接近1。该小样本提示先检查阈值敏感性；完整结论需统计全部200回合。所查记录为：

## 3 夹爪优先标定

先检查指令分布、切换附近的中间值和事件位置随阈值的变化。保留0.2作对照，从200回合的实际分布中选能改变事件识别的少量候选；产生完全相同开闭事件的门槛合并，不重复跑闭环。若分界在一段范围内均不影响识别，保留0.2并报告该稳定范围。

确认长度先离线比较1、2、3步，统计新增、消失和位置变化的开闭事件，以及单步反转与持续切换。只保留最多两套有不同作用的夹爪候选进入闭环。

这里的确认读取预测中的未来连续动作，不是等机械臂实际执行完这些步再发现事件；比较时分别记录事件开始位置和确认窗口，不能把确认长度直接当作新增控制延迟。

当前confirm_steps同时用于夹爪、减速、转向、新旧动作比较等逻辑。后续实现独立的gripper_confirm_steps，默认沿用原值2；夹爪实验仅修改开闭事件的确认长度，其他信号的窗口保持2。减速与转向参数暂不同时调整。

代码涉及[事件配置与检测](/home/wyk/workspace/PerceptBudget/perceptbudget/action_events.py)、[线上剩余动作提取](/home/wyk/workspace/PerceptBudget/perceptbudget/critical_forecast.py)及其配置入口。此处是待实现范围，本轮不修改代码或FlashRT。

## 4 小样本闭环和后续选择

从旧200回合预先固定12个开发样本，每个集合3个，包含成功和失败；按统一分层规则抽取，名单在运行前记录。所有候选共用同一批seed、init和任务，不按单个任务更换参数。

比较原参数与最多两套夹爪候选，共最多36回合。每套按seed合并加载模型，复用已有环境缓存。统计同批成功数、含失败的任务总能量、平均刷新间隔、请求次数，以及夹爪事件实际改变了哪些刷新。原参数在这批中一并运行，用于观察真实异步的运行波动。

如果离线回放中没有实际差异，不为凑候选启动闭环。若出现小幅成功数变化，先看它是否伴随实际事件和接续变化，再决定是否扩大验证。只增加推理次数、能耗明显上升的方案不因救回单个任务直接采用。

夹爪阶段结束后，再按相同流程分别标定减速比例与最小运动门槛、转向角度。先从旧记录筛选少量有效范围，再做单项对照；不穷举全部参数的笛卡尔积，不一次修改所有门槛。

最终固定一套全任务共用参数，用新seed完整测试成功率、总能量和刷新间隔，并给出邻近参数的敏感性结果。论文如实报告人工初值、开发集标定过程和独立测试结果，不将当前默认值描述为已证明最优。

交付包括200回合分布统计、开闭事件时间线、候选与固定开发名单、闭环对照表，以及参数选择依据。最终v4配置保持冻结，历史37版的运行快照继续保留。

## 5 已完成的离线分析 2026年11月11日

200回合全部完成读取，原记录172成功、28超时。共76,350条预测动作，仅12条夹爪幅值小于0.2，76,163条幅值距1不超过0.1。已保存的1,327段线上预测用相同输入回放，夹爪事件完全一致；全部执行动作与来源预测的索引、计划数值均一致。

| 夹爪参数扰动 | 闭爪预测变化段数 | 涉及回合 |
|---|---:|---:|
| 分界0.2改0.1 | 1 | 1 |
| 分界0.2改0.3 | 0 | 0 |
| 分界0.2改0.5 | 0 | 0 |
| 确认2步改1步 | 8 | 7 |
| 确认2步改3步 | 16 | 16 |

这些是离线敏感性扰动，不是已经选定的生产参数。0.5另改变两段开爪预测；表中只统计闭爪。确认长度比较只改变夹爪未来窗口，保持原有两步历史，其他事件不参与此项比较。

190回合实际执行过闭爪指令，其中163成功、27失败；这些回合的首次闭爪均能在已保存预测中找到相同目标步。成功与失败的首次闭爪观测年龄中位为9步与12步，接管后到闭爪中位为2步与4步。Object分项为成功41回合、失败9回合，观测年龄中位8步与18步，接管后调整窗口中位2步与7步。失败侧没有普遍更短的调整窗口，不能直接归结为“只要多提前几步接管就能解决”。

目前证据不支持优先扫夹爪分界0.2；确认窗口有实际影响，但效果仍需闭环。下一步先复核闭爪前接近、减速、接触和最近有效观测，区分过早闭爪、推偏后闭爪及后续松脱，再提出统一候选。最近物体中心距离和手指接触只能辅助查轨迹，不能单独标注是否抓住或是否过早。

## 6 Object抓取接触复核

进一步检查旧200回合中的全部50个Object回合，41成功、9超时。仅离线按任务文字确定目标物，读取已有物体位姿、夹爪开度、手指接触和输入图像；这些目标标签不进入线上机制，也没有重新运行仿真或模型。

- 9个失败中7个全程目标抬升不足20mm，机械臂已进入抬起与后续动作；另外2个曾抬起再掉落。
- 两个掉落样本在掉落前后的指令始终为闭爪。seed67/Object2在61步抬到峰值，63步已下降超过20mm，111步才开爪；seed109/Object5在76步达峰值，78步已下降超过20mm，123步才开爪。两例物体下降时机械臂仍向上。
- 失败中8/9在首次闭爪前10步已有手指与目标接触，但没有一例在这个窗口中目标平移达到10mm。从动作源观测到闭爪的目标平移中位数，成功约4.75mm、失败约4.98mm，本批并非普遍大幅推走目标。
- 同任务比较需与总体统计区分。牛奶盒成功2回合的观测年龄17、18步，失败3回合16、17、16步；失败并非观测更旧。闭爪时末端高于目标中心的中位数，成功约45mm、失败约63mm，支持继续检查接近位置是否到位。该相对高度不是通用抓取阈值，需结合手指姿态和接触看待。

当前更适合优先校准抓取前接近阶段的减速、转向与闭爪事件关系，并核对空夹后反馈；单凭观测年龄不能决定是否刷新，单凭闭爪指令不能判断已抓稳。后续统一参数仍从全200回合中选取，包含其他任务类型与成功对照。最终v4继续冻结。
