# 视觉异常监测实验

项目：PerceptBudget。整体方案仍使用“v4基线”，冻结标签为`v4-final-20261111`；本目录只管理在该基线上增加的图像监测实验。

## 当前目标：报得准

以用户最新要求为准：先检查报警是否对应真实异常，不以报警后任务成功与否评价检测器。图像与机械臂状态须相互印证；只看到画面变化记为未确认，不触发报警。逐条用独立的图像、物体运动与接触记录核对，分别保留正确报警、误报、无法确认和漏检；没有报警的片段不能自动算作正常。

## 响应方式

检测方法与响应方式分别记录，不混成另一个“版本”：

- 只记录：`--visual-monitor observe`。
- 报警停等：`--visual-monitor refresh --visual-response stop_and_replan`。立即暂停旧动作，采最新双图重新预测；这次不使用已出错的旧动作作RTC目标。
- 异步刷新：`--visual-response async`。用于复现最初的小测，报警后仍执行旧动作。

当前实验方向是“更新参考监测＋抓取检查”，准确性评估可使用`observe`只记录，响应方式单独选择。整体v4默认不启用图像监测。

“抓取检查”是更新参考监测的可选功能，使用`--visual-grasp-check`启用：夹口接近当前回合观测到的闭合极限、手已抬起时，检查夹爪附近纹理是否仍随手保持稳定。每次闭爪最多追加两次状态触发采图，纹理不足时不下判断。启用后，单纯持续纹理丢失仅记为未确认变化；保留夹口塌缩与纹理丢失、空夹口抬手与相对视觉运动这两类联合证据报警。该功能仍按旧开发数据和少量闭环验证推进，不新增另一套版本编号。
