### 计时与运行模式

- 仿真任务时间 = **正式控制步数 × 0.05秒**。
- 真实 wall-clock 从正式任务开始计至结束，包含推理、等待和调度开销；同步推理暂停仿真的等待不增加控制步时间，但计入 wall-clock。两种时间分别报告，不用单次推理时间替代。
- 本轮标明 **同步诊断**。同步结果不能当作异步闭环结果，也不能据此声称异步节能。
- 成功、失败和超时分别记录；失败不伪造成功完成时间。只在共同成功的相同任务间比较完成时间，并同时报告成功次数。
